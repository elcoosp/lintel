# LNT0203 — component has no such parameter

`error[LNT0203]` · validation diagnostic (error severity) · `UnknownPropRule` (§7.1 typed-component checks)

## What fires it

A component invocation passes a prop the component's signature does not
declare:

```php
<?php
function Badge(string $label): Html { return <span>{$label}</span>; }
return <Badge label="Hi" colour="red" />;
```

```text
error[LNT0203]: component `Badge` has no parameter `$colour`
```

The validator reads the component's in-file signature (§7.1) and rejects
every prop that does not match a declared parameter. This catches typos
at compile time — `colour` instead of `color` — before the prop silently
vanishes into a PHP named-argument error at render time.

## Fix

Either add the parameter to the component's signature (`function Badge(string $label, string $colour = '')`), or correct the prop name to match
an existing parameter. Spread attributes (`{...$attrs}`) are not checked
per-key against the signature — the runtime routes each key through the
attribute helpers instead.
