# LNT0302 — static event-handler string

`warning[LNT0302]` · validation diagnostic (warning severity — advisory) · `StaticHandlerRule` (§7.1 "no JS-in-attribute from data")

## What fires it

A static event-handler attribute (`onclick="..."`) is present:

```php
<?php
return <button onclick="track('cta')">Go</button>;
```

```text
warning[LNT0302]: static event-handler attribute `onclick` is discouraged
  = help: attach behaviour in JavaScript via `data-action` + a listener, or an
          `hx-*` / `x-on:*` binding (CSP nonce-safe, tree-shakeable)
```

## Why it is a warning, not an error

A static `onclick="..."` is not an XSS sink (the value is a literal the
author wrote, not dynamic data), so it does not bypass the escape-by-
default invariant. But inline JavaScript bypasses Content-Security-Policy
nonces and cannot be tree-shaken, so Lintel warns and points at the
`data-action` pattern instead.

## Fix

Move the handler to a `data-action` attribute and attach the listener in
JavaScript, or use an `hx-*` (HTMX) / `x-on:*` (Alpine) binding. A
dynamic `onclick={$handler}` is LNT0301 (an error) — the static form is
the advisory lane here.
