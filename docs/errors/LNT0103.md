# LNT0103 — invalid attribute

`error[LNT0103]` · parse diagnostic (never suppressible) · scanner (§6.3)

## What fires it

An attribute cannot be parsed — the name is malformed, the value is
missing its closing quote, or the attribute shape is not one the grammar
recognises:

```php
<?php
return <a href=>link</a>;
```

```text
error[LNT0103]: invalid attribute
```

Attributes come in four shapes: `name` (bare boolean), `name="static"`,
`name={expr}` (dynamic), and `{...spread}`. Anything else — a `=` with no
value, an unquoted dynamic value, a stray `>` — is a parse error. The
scanner reports it at the attribute's position so the author fixes the
shape, not the surrounding element.

## Fix

Use one of the four recognised attribute shapes. A dynamic value rides
`name={expr}`; a static string rides `name="..."`; a boolean flag rides
`name` alone; a spread rides `{...$attrs}`. Quote every static string.
