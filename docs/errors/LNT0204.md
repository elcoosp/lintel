# LNT0204 — component does not accept children

`error[LNT0204]` · validation diagnostic (error severity) · `UnexpectedChildrenRule` (§7.1 typed-component checks)

## What fires it

A component invocation passes children to a component whose signature
declares no `children` parameter:

```php
<?php
function Badge(string $label): Html { return <span>{$label}</span>; }
return <Badge label="Hi">extra children</Badge>;
```

```text
error[LNT0204]: component `Badge` does not accept children
```

The validator checks the component's signature for a `$children`
parameter; if absent, passing children is a compile-time error. This
catches the common mistake of treating a leaf component as a container.

## Fix

Either add a `children` parameter to the signature (`function Badge(string $label, Html $children): Html`), or remove the children from the
invocation (`<Badge label="Hi" />`).
