# LNT0205 — required component parameter missing

`error[LNT0205]` · validation diagnostic (error severity) · `MissingRequiredPropRule` (§7.1 typed-component checks)

## What fires it

A component invocation omits a required parameter (one without a default):

```php
<?php
function Badge(string $label, bool $verified = false): Html { return <span>{$label}</span>; }
return <Badge />;
```

```text
error[LNT0205]: component `Badge` requires parameter `$label`
```

The validator reads the component's signature and rejects any invocation
that omits a required parameter. This catches the missing-prop mistake at
compile time — before PHP would fatal with a `TypeError` at render time.

## Fix

Pass the required parameter: `<Badge label="Hi" />`. Optional parameters
(those with a default) may be omitted; the lowering emits the default
only for explicitly absent props the signature declares.
