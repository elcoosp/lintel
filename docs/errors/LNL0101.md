# LNL0101 — unterminated tag

`error[LNL0101]` · parse diagnostic (never suppressible) · scanner (§6.3)

## What fires it

An element or tag is opened but never closed before the source ends:

```php
<?php
return <div>
    <span>text
;
```

```text
error[LNL0101]: unterminated tag `<div>`
  = help: close every element you open (`</div>`)
```

The scanner reaches end-of-source with one or more elements still on its
open-element stack. The emitted PHP would otherwise leave a string
concatenation unbalanced — the line-preserving invariant (§3) requires
every JSX region to close on the source's own lines.

## Fix

Close every element you open, in the order you opened it. A fragment
(`<>...</>`) closes with `</>`. A self-closing element (`<br />`) needs
no close tag. The `lintl-ignore-next` directive cannot suppress a parse
error — unterminated tags are never suppressible.
